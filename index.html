📤 Upload de anexos (GitHub)

Pra o botão "📎 Anexo" enviar o arquivo de verdade pro repositório (em vez de só guardar o nome), cole aqui um token de acesso do GitHub. Só precisa fazer isso uma vez por navegador/aparelho.

Como gerar: no GitHub, vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Em "Repository access" escolha "Only select repositories" → painel-seca-barriga. Em "Permissions" → "Repository permissions" → marque Contents: Read and write. Gere e copie o token (começa com github_pat_...).

⚠️ O token fica salvo só neste navegador (não é enviado a mim nem a mais ninguém). Não compartilhe esse token — quem tiver acesso a ele pode alterar arquivos do repositório.
